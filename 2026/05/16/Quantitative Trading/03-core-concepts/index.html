一、收益相关指标

1.1 年化收益率（Annualized Return）

定义: 将不同时间周期的收益率转换为年度收益率，便于比较。

公式:

示例:

  • 策略A：3个月收益10% → 年化 = (1+0.10)^4 - 1 = 46.4%
  • 策略B：1年收益30% → 年化 = 30%

⚠️ 注意: 短期高收益年化后可能失真，需结合其他指标评估。

1.2 超额收益（Alpha, α）

定义: 跑赢基准的收益部分，即”真正的赚钱能力”。

示例:

  • 策略收益: 15%
  • 基准收益（沪深300）: 10%
  • Alpha: 15% - 10% = 5% ✅

1.3 胜率（Win Rate）

定义: 盈利交易次数占总交易次数的比例。

胜率水平 评价
> 60% 优秀
50-60% 良好
40-50% 一般（需高盈亏比弥补）
< 40% 较差（除非盈亏比极高）

💡 注意: 高胜率不等于高收益。胜率40%但盈亏比3:1的策略，长期可能盈利。

1.4 盈亏比（Profit/Loss Ratio）

定义: 平均盈利金额与平均亏损金额的比值。

示例:

  • 平均盈利: ¥300
  • 平均亏损: ¥100
  • 盈亏比: 3:1

盈亏比与胜率的关系:

胜率 所需盈亏比（盈亏平衡）
80% 0.25:1
60% 0.67:1
50% 1:1
40% 1.5:1
30% 2.33:1

二、风险相关指标

2.1 波动率（Volatility）

定义: 收益率的标准差，衡量收益的波动程度。

年化波动率:

波动率水平 评价
< 10% 低风险
10-20% 中等风险
20-30% 较高风险
> 30% 高风险

2.2 最大回撤（Max Drawdown）

定义: 从峰值到谷底的最大亏损幅度，衡量最坏情况下的亏损。

示例:

⚠️ 重要性: 最大回撤直接影响投资者的心理承受能力和策略容量。

2.3 回撤恢复期（Drawdown Duration）

定义: 从回撤谷底恢复到前期峰值所需的时间。

恢复期 评价
< 3个月 优秀
3-6个月 良好
6-12个月 一般
> 12个月 较差

三、风险调整收益指标

3.1 夏普比率（Sharpe Ratio）⭐

定义: 每承担一单位风险所获得的超额收益。

评价标准:

夏普比率 评价
< 1.0 较差
1.0 - 2.0 良好
2.0 - 3.0 优秀
> 3.0 卓越（罕见）

示例:

  • 策略年化收益: 20%
  • 无风险利率: 3%
  • 年化波动率: 15%
  • 夏普比率 = (20% - 3%) / 15% = 1.13 ✅

3.2 卡玛比率（Calmar Ratio）

定义: 年化收益率与最大回撤的比值。

评价标准:

卡玛比率 评价
< 1.0 较差
1.0 - 2.0 良好
2.0 - 3.0 优秀
> 3.0 卓越

示例:

  • 年化收益: 30%
  • 最大回撤: 15%
  • 卡玛比率 = 30% / 15% = 2.0 ✅

3.3 索提诺比率（Sortino Ratio）

定义: 与夏普比率类似，但只考虑下行风险。

优势: 比夏普比率更合理，因为投资者只关心下行风险。

3.4 收益风险指标对比

指标 公式 侧重点
夏普比率 (收益-无风险利率)/总波动 总风险调整收益
卡玛比率 年化收益/最大回撤 极端风险调整收益
索提诺比率 (收益-无风险利率)/下行波动 下行风险调整收益

四、量化专用术语

4.1 基础术语

术语 英文 解释
因子（Factor） Factor 能解释资产收益差异的变量
信号（Signal） Signal 触发交易决策的指标或条件
回测（Backtest） Backtest 在历史数据上模拟策略表现
滑点（Slippage） Slippage 下单价格与实际成交价格的差异
换手率（Turnover） Turnover 一段时间内交易金额/总资产

4.2 风险术语

术语 解释
过拟合（Overfitting） 策略过度适应历史数据，泛化能力差
前视偏差（Look-ahead Bias） 回测中使用了未来才知道的信息
幸存者偏差（Survivorship Bias） 只考虑存活下来的样本，忽略已退市的
曲线拟合（Curve Fitting） 用过多参数拟合历史数据
数据挖掘偏差（Data Mining Bias） 通过大量尝试偶然发现”有效”策略

4.3 策略术语

术语 解释
多头（Long） 买入持有，预期上涨
空头（Short） 借入卖出，预期下跌
对冲（Hedge） 用相反头寸降低风险
杠杆（Leverage） 借入资金放大收益/亏损
保证金（Margin） 交易所需的抵押资金

4.4 Beta（β）详解

定义: 衡量资产相对于市场的系统性风险。

Beta值 含义
β = 1 与市场同步波动
β > 1 比市场波动更大（激进）
β < 1 比市场波动更小（保守）
β = 0 与市场无关
β < 0 与市场反向波动（罕见）

示例:

  • 某股票β=1.5，市场涨10%，股票涨15%
  • 某股票β=0.5，市场跌10%，股票跌5%
