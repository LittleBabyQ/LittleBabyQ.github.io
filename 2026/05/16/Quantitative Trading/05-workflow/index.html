一、总体流程概览

量化交易是一个循环迭代的过程，从数据到策略再到实盘，不断优化和改进。

二、Step 1: 数据获取

2.1 数据类型

数据类型 内容 频率 用途
行情数据 OHLCV、买卖盘 Tick/分钟/日 技术分析、回测
基本面数据 财务报表、估值 季度/年度 因子投资
宏观数据 GDP、CPI、利率 月度/季度 宏观策略
情绪数据 新闻情绪、搜索指数 实时 另类策略
另类数据 卫星图像、船运数据 不定期 特殊策略

2.2 免费数据源

数据源 覆盖市场 数据类型 获取方式
Yahoo Finance 美股、ETF 日线 Python yfinance库
AKShare A股、期货、期权 多类型 Python akshare库
Tushare A股 多类型 Python tushare库（积分制）
Baostock A股 日线、分钟线 Python baostock库
FRED 美国经济数据 宏观数据 API免费

三、Step 2: 数据清洗

3.1 常见问题

问题 说明 解决方法
缺失值 某些日期没有数据 前向填充、插值、删除
异常值 价格突然跳变 检测并修正或删除
复权处理 除权除息影响价格 前复权或后复权
时间对齐 不同数据源时间戳不一致 统一时间格式
停牌处理 股票暂停交易 标记或填充

4.2 特征选择

方法 说明

五、Step 4: 策略回测

5.1 回测框架选择

框架 特点 适用场景
Backtrader 功能全面，社区活跃 中低频策略
VectorBT 向量化回测，速度快 大量参数优化
Zipline Quantopian开源，文档好 美股策略
QuantConnect 云端，多语言支持 需要云计算

5.2 Backtrader回测示例

5.3 回测评价指标

指标 说明 优秀标准
年化收益率 策略一年的收益率 > 10%
夏普比率 风险调整后收益 > 1.0
最大回撤 最大亏损幅度 < 20%
胜率 盈利交易占比 > 50%
盈亏比 平均盈利/平均亏损 > 1.5

实际应用: 通常使用”半凯利”或”四分之一凯利”，降低风险。

6.3 止损策略

止损类型 说明 适用场景
固定比例止损 亏损达5%止损 简单明了
移动止损 盈利后回撤10%止损 保护利润
时间止损 持仓N天后无条件平仓 避免长期套牢
波动率止损 基于ATR设置止损 适应市场波动

七、Step 6: 实盘交易

7.1 连接券商API

券商/平台 API特点 适用市场
Interactive Brokers 功能全面，支持全球市场 美股、期货
Alpaca 零佣金，API友好 美股
富途/老虎 中文支持好 港股、美股
聚宽/米筐 国内量化平台 A股
币安/OKX 加密货币 数字货币

7.2 实盘注意事项

事项 说明
从小资金开始 先用小资金验证策略
模拟盘过渡 至少模拟盘运行1-3个月
监控滑点 实盘滑点通常比回测大
系统稳定性 确保服务器稳定，网络畅通
异常处理 设置自动止损和报警机制

八、Step 7: 监控与优化

8.1 监控指标

指标 监控频率 异常处理
策略收益 每日 连续亏损超过阈值暂停
最大回撤 实时 超过预设值减仓或暂停
胜率变化 每周 胜率显著下降检查策略
滑点情况 每笔交易 滑点过大检查执行逻辑
系统状态 实时 故障自动切换备用系统

8.2 策略优化

8.3 策略失效判断

现象 可能原因 应对措施
连续亏损 市场环境变化 暂停，分析原因
回撤超预期 策略过拟合 简化策略，重新训练
胜率骤降 竞争加剧 寻找新的Alpha
收益下降 因子失效 开发新策略
